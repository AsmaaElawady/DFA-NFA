# DFA & NFA Automata Simulator

This project simulates 10 problems using Deterministic and Nondeterministic Finite Automata (DFA & NFA) in Java. It processes structured input from a file, determines acceptance based on automaton rules, and writes the output to a file following a specified format.


## 🧠 Problem Overview

| Problem | Automaton | Description |
|--------|-----------|-------------|
| 1 | DFA | Accept strings over {a, b} that **do not** contain an even number of `a`s |
| 2 | DFA | Accept binary strings that **start with `1`** and have **length ≥ 3** |
| 3 | DFA | Accept strings over {x, y, z} containing substring `"xyz"` |
| 4 | DFA | Accept binary strings representing numbers **divisible by 7** |
| 5 | DFA | Accept strings where **every `a` is in a consecutive pair** |
| 6 | DFA | Accept strings with **even number of `a`** and **odd number of `b`** |
| 7 | NFA | Accept binary strings with **at least one `0` and `1`**, **no more than two identical digits in a row** |
| 8 | NFA | Accept strings over {a, b} where substring `"ab"` appears **at least twice** |
| 9 | NFA | Accept binary strings where **every `1` is followed by at most one `0`** |
|10 | NFA | Accept strings over {x, y} where **no two `y`s appear consecutively** |
